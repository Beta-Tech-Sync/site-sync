# site-sync

This repository currently contains Visual Studio workspace metadata, rather than a buildable application.

The active SiteSync application and release work are in [Beta-Tech-Sync/Beta-Site-Sync](https://github.com/Beta-Tech-Sync/Beta-Site-Sync).

To use this as a separate source repository, add the application source and project files first. Local IDE state, credentials, build outputs, and databases should not be committed. Existing tracked `.vs` files remain in history; adding `.gitignore` does not remove previously tracked files.
